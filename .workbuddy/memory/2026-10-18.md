### 方法论补记

- playwright 在本机的可用姿势：包在 `/Users/bright/github/playwright-mcp/node_modules`，
  无 ms-playwright 浏览器缓存 → `chromium.launch({ channel: 'chrome' })` 走系统 Chrome；
  脚本需 .cjs 且放在该目录下跑（ESM/package type 坑）。
- hover computed-style 采样必须**等满 transition**（waitForTimeout≥450ms），否则读到插值中间色
  （本轮两次 FAIL 都是采样时机问题，非规则问题：border-color transition .18s 在 150ms 时仅 95.7% 进度）。
- BSD grep 的 `\b` 与 `--` 前缀模式不可靠（`grep "\.x\b"`、`grep "--token"` 静默零结果），
  类名/规则查询统一用 Grep 工具或 python 正则。
- 特异性陷阱：专属上下文规则（`.row .card:hover`）按特异性覆盖通用规则（`.card:hover`），
  与参考站 grid--subscription/top_up 层级行为一致——测试断言要按最终生效值写。
