# 货觉AI · 后台界面设计

版本 v1.0 ｜ 2026-10-19 ｜ 上游：`docs/admin-prd.md`（需求）· `docs/admin-detailed-design.md`（逻辑）

> **文档状态**：视觉与布局依据。页面数量与分组已随 B1–B8 扩展（当前 28 页），模型配置页改版为 antd 原生组件；当前清单见 [`CLAUDE.md`](../CLAUDE.md)「后台管理端」。

本文描述**页面长什么样**。逻辑与接口见详细设计。

## 0. 设计原则

| 原则 | 说明 |
|---|---|
| 令牌复用 | 只用 `global.css` 已有令牌（263 个），**不新增裸 hex**。新样式前缀 `adm-` |
| 密度优先 | 后台是长时间使用的工具，信息密度高于 C 端营销页。表格行高 44px，间距紧凑 |
| 少装饰 | 无渐变、无大圆角、无插画。阴影仅用于浮层 |
| 操作可见 | 关键操作紧邻数据，不藏在菜单深处 |
| 状态可辨 | 状态用色块 + 文字双编码，不只靠颜色（色觉障碍可达性） |
| 反馈及时 | 任何操作有 loading / 成功 / 失败三态，失败给可读原因 |

### 0.1 令牌映射

| 用途 | 令牌 | 值 |
|---|---|---|
| 页面底色 | `--surface` | `#f2f4f7` |
| 卡片/面板 | `#fff` | 白色实底 |
| 主色 | `--brand` | `#5546d8` |
| 主色浅底 | `--brand-bg` | `#f1efff` |
| 主色悬停 | `--brand-hover` | `#5b4bd7` |
| 标题文字 | `--text-strong` | `#171a2b` |
| 正文 | `--text-body` | `#4e5969` |
| 次要文字 | `--text-muted` | `#667085` |
| 描述小字 | `--text-desc` | `#86909c` |
| 常规边框 | `--border` | `#e5e7ef` |
| 行分隔线 | `--border-row` | `#eff0f4` |
| 卡片圆角 | `--radius-card` | 12px |
| 面板圆角 | `--radius-panel` | 16px |
| 控件圆角 | `--radius-control` | 8px |
| 卡片阴影 | `--shadow-card` | 轻投影 |

**后台专用状态色**（复用现有，不新增）：

| 语义 | 令牌 | 用途 |
|---|---|---|
| 成功 | `--success` / `--success-bg` | 订单完成、通道正常 |
| 警告 | `--warn-bg` / `--warn-border` | 积分离将过期、待处理 |
| 危险 | `--danger` / `--danger-bg` | 退款、删除、失败 |
| 处理中 | `--brand-bg` | 订单支付中、任务运行中 |

### 1.2 Header

| 区域 | 内容 | 规格 |
|---|---|---|
| 左 | Logo + 「运营后台」 | Logo 28px，文字 15px/600 `--text-strong` |
| 中 | 留白 | — |
| 右：搜索 | 全局搜索框 | 宽 240px，placeholder「搜索用户 / 订单 / 素材」，快捷键 `⌘K` |
| 右：环境 | 环境徽标 | 仅非生产环境显示。`开发`/`预发` 用 `--warn-bg`，生产不显示 |
| 右：告警 | 铃铛 + 未读数 | 有未读告警时显示红色角标 |
| 右：用户 | 头像 + 邮箱 + 角色 | 点击展开：个人信息 / 切换账号 / 退出 |

**环境徽标设计**：只在非生产环境显示，避免误在生产执行测试操作。这是安全设计，不是装饰。

### 1.3 Sider

| 项 | 规格 |
|---|---|
| 宽度 | 240px 固定 |
| 背景 | `#fff`，右边框 1px `--border` |
| 分组标题 | 12px/600 `--text-desc`，padding `20px 16px 8px`，不可点击 |
| 菜单项高 | 40px，圆角 `--radius-control` |
| 菜单项内 | 图标 18px + 文字 14px，间距 10px，padding `0 12px` |
| 悬停 | 底色 `--brand-bg` |
| 选中 | 底色 `--brand-bg`，文字 `--brand`，字体 600，左侧 3px `--brand` 指示条 |
| 折叠 | 支持。折叠态宽 64px，仅图标，hover 展开为浮层 |
| 底部 | 当前管理员信息，点击展开菜单 |

**菜单项按权限过滤**：无权访问的项不渲染（不是禁用 —— 禁用会让用户困惑"为什么在这里又点不动"）。

### 1.4 响应式

| 宽度 | 行为 |
|---|---|
| ≥ 1440px | 完整布局 |
| 1280–1439px | Sider 保持 240px，表格横向滚动 |
| < 1280px | Sider 自动折叠为 64px 图标栏 |
| < 1024px | 提示「请使用更大屏幕」，后台不做移动端适配 |

**不做移动端**：运营人员使用桌面。移动端表格无法承载信息密度，做出来也是摆设。

### 1.5 加载与骨架

| 场景 | 表现 |
|---|---|
| 首屏 | 侧栏骨架 + 内容区骨架块，不显示全屏 spinner |
| 列表翻页 | 表格区骨架（保留表头），不整页闪烁 |
| 抽屉打开 | 抽屉内骨架 |
| 按钮提交 | 按钮内 spinner + 禁用，不遮挡页面 |
| 统计卡 | 卡片内骨架，保持布局不跳动 |

## 2. 页面通用结构

### 2.1 PageHeader

```
┌──────────────────────────────────────────────────────────┐
│ 用户管理                                    [导出] [+ 新建]│
│ 管理注册用户的账号状态、角色与资源                          │
└──────────────────────────────────────────────────────────┘
```

| 元素 | 规格 |
|---|---|
| 标题 | 20px/600 `--text-strong` |
| 描述 | 13px `--text-muted`，可省略 |
| 主操作 | 实心按钮，`--brand` 底 |
| 次操作 | 描边按钮，置于主操作左侧 |

### 2.2 FilterBar

```
┌──────────────────────────────────────────────────────────────────┐
│ [搜索关键词        🔍] [角色 ▾] [状态 ▾] [注册时间 📅] [查询] [重置] │
└──────────────────────────────────────────────────────────────────┘
```

| 规则 | 说明 |
|---|---|
| 布局 | 左侧筛选控件自动换行，右侧「查询/重置」固定 |
| 触发 | 查询按钮点击生效（不做每键即查，避免无意义请求） |
| 重置 | 清空全部筛选并回到第 1 页 |
| 条件回显 | 已生效的筛选以 Tag 形式显示在结果区上方，可单独移除 |

### 2.3 表格

```
┌────────────────────────────────────────────────────────────────────┐
│ ☐ │ 邮箱                │ 状态  │ 角色   │ 注册时间   │ 操作      │
├────────────────────────────────────────────────────────────────────┤
│ ☐ │ a@x.com             │ ● 正常│ 运营   │ 2026-10-01│ 详情 · 更多▾│
│ ☐ │ b@x.com             │ ● 正常│ 用户   │ 2026-10-02│ 详情 · 更多▾│
└────────────────────────────────────────────────────────────────────┘
        共 1,240 条    [<] 1 2 3 ... 62 [>]   每页 [20 ▾] 条
```

| 规则 | 规格 |
|---|---|
| 行高 | 44px |
| 表头 | 背景 `#fff`，12px/600 `--text-muted`，不排序的列不加图标 |
| 排序 | 仅数值与时间列可排序，点击切换升/降序 |
| 多选 | 表格左上角全选，选中后顶部浮出批量操作条 |
| 操作列 | 固定右侧，宽度 ≥ 120px。最多直显 2 个动作，其余收进「更多」下拉 |
| 分页 | 右下角，`showSizeChanger`，选项 20/50/100 |
| 空态 | 居中 Empty 图标 + 说明 + 「重置筛选」按钮（有筛选时）或「新建」按钮（无筛选时） |
| 加载失败 | Result 警告态 + 「重试」按钮，保留筛选条件 |

**操作收纳原则**：高频操作直显（详情、编辑），低频收进「更多」（删除、重置密码）。全部平铺会让操作列宽到 400px，挤掉数据列。

### 2.4 详情抽屉

```
     ┌────────────────────────────────────────────┐
     │ 用户详情                              [×]  │  ← 720px 宽
     ├────────────────────────────────────────────┤
     │  [描述列表：邮箱/昵称/角色/状态/注册/登录]    │
     ├────────────────────────────────────────────┤
     │ 统计卡  [项目 12] [任务 89] [素材 45] [消费 ¥380]│
     ├────────────────────────────────────────────┤
     │ 最近任务                    [查看全部]      │
     │ 表格...                                    │
     ├────────────────────────────────────────────┤
     │ 积分概览  余额 2,340 · 7日内过期 300         │
     ├────────────────────────────────────────────┤
     │ [禁用账号]              [重置密码] [删除]     │  ← 底部固定
     └────────────────────────────────────────────┘
```

| 规则 | 规格 |
|---|---|
| 宽度 | 720px |
| 高度 | 100vh，内容区独立滚动 |
| 头部 | 标题 + 关闭。标题旁可带状态 Tag |
| 底部操作栏 | 固定底部，左侧次要、右侧危险（删除） |
| 懒加载 | 打开才请求详情，关闭清空 |
| 嵌套抽屉 | 不支持。点击关联对象跳转到对应页面而非再开一层 |

**不做嵌套抽屉**：抽屉套抽屉会让用户迷失。关联对象（如订单、任务）跳转到对应列表并带上筛选条件。

### 2.5 确认弹窗

```
┌──────────────────────────────────────────┐
│ ⚠ 删除用户                               │
├──────────────────────────────────────────┤
│ 将永久删除该用户的数据：                   │
│   · 12 个项目                           │
│   · 45 张素材（含磁盘文件）               │
│   · 89 条任务记录                       │
│   · 8 条积分流水                         │
│                                          │
│ 订单与支付记录将保留（法定留存 3 年），     │
│ 但用户信息将被匿名化。                    │
│                                          │
│ 此操作不可恢复。请输入「删除」以确认：    │
│ [____________]                           │
│                                          │
│              [取消]  [确认删除]           │
└──────────────────────────────────────────┘
```

| 规则 | 说明 |
|---|---|
| 影响面量化 | 必须列出具体数量，不写「将删除相关数据」 |
| 需输入确认 | `user.delete` `asset.delete` `order.refund` `credit.adjust` `setting.write` |
| 危险按钮 | `--danger` 底色，不与其他按钮相邻 |
| 不可撤销提示 | 有破坏性的操作必须明示 |

### 2.6 统计卡

```
┌────────────────┐
│ 用户总数        │  12px `--text-muted`
│ 1,240          │  24px/600 `--text-strong`
│ ↑ 8.2% 较上周   │  12px 成功/危险色
└────────────────┘
```

| 规则 | 规格 |
|---|---|
| 尺寸 | 高 96px，padding 16px 20px |
| 数值 | 24px/600，超过 10000 显示 `1.2万` |
| 趋势 | 有真实对比期才显示。不显示 `↑0%` |
| 配色 | 默认白底。异常态（余额为负、超阈值）用 `--danger-bg` |

**不上无意义数字**：没有对比期的指标不显示趋势箭头。显示 `↑0%` 是在制造噪音。

## 5. 项目与素材

### 5.1 项目列表 `/admin/projects`

结构同用户管理。列：项目名 / 所属用户 / 素材数 / 任务数 / 创建时间 / 操作。

**树形权限结构**：父级（模块）与子级（动作）分级。取消父级时子级全部取消。

**三列对照**：横向对比三个角色的差异，比逐个角色查看直观。

## 附录 B · 可达性

| 项 | 要求 |
|---|---|
| 状态标识 | 颜色 + 图标 + 文字三重编码 |
