> 结论先行：**推荐「货觉AI」**。生造词、零冲突、商标友好、语义与产品机制同构。

## 0. 结论

| 项 | 内容 |
|---|---|
| **推荐名** | **货觉AI**（Huòjué AI） |
| 结构 | 货（商品）× 觉（感知）+ AI（品类后缀，参考站同款构词法） |
| 释义 | AI 对商品的感知——看清每一件货，生成对的图 |
| 读音 | huò jué，朗朗上口；无负面谐音（「获爵」为雅谐音） |
| 商标显著性 | **生造词**（汉语中无此固定词），显著性远高于「商图/货视」类描述性词组 |
| 冲突核查 | 联网核查**零同名品牌/公司/平台**（见 §3） |
| 域名建议 | huojue.com / huojue.ai（**未核查可注册性**，落地前需查） |

## 1. 三个候选（按推荐排序）

### ① 货觉AI —— 推荐（感知派）

| 维度 | 评估 |
|---|---|
| 语义 | 货=商品（资产），觉=感知（视觉/直觉/识别）——「对商品的感知」正是产品机制：上传货 → AI 感知 → 生成对的图 |
| 记忆度 | 生造词自带记忆点；两字+AI，四音节，口播友好 |
| 延展性 | 「觉」可延展出产品线命名（货觉·主图 / 货觉·详情 / 货觉·商拍），不锁死在单一功能 |
| 风险 | 无明显负面联想；需防跟风仿冒（生造词共性问题） |
| Logo 契合 | 「觉眼」主标记（眼廓+星瞳）与名字互文，见 `docs/brand/brand-basics.md` |

### ② 商拍AI（行业术语派）

商拍=商业摄影（卖家已知的行业词），「AI 商拍」= 用 AI 替代商拍。可信度高、零解释成本。
**劣势**：商拍是品类通用词，多家摄影/ SaaS 在用类似表述，品牌独占性弱；且把品类锁在「拍摄替代」上，而产品实际覆盖抠图/翻译/精修等拍摄后能力。

### ③ 货生图（机制派）

沿「文生图/图生视频」构词法：货生图。机制一目了然、有传播梗。
**劣势**：像功能名而非品牌名；「生图」二字把品类写死为「生成」，而产品一半能力是编辑/精修/翻译。

## 2. 为什么不延续「电商视觉工坊」

- **品类通用词**：描述性词组，无商标显著性，任何竞品都能用
- **六字长度**：不利口播与缩写；顶栏/登录页等窄位显示拥挤（实测原品牌块比新名宽 ~30px）
- **命名代差**：对标参考站「极画AI」已是「二字+AI」的品类命名法，通用词描述在产品名位上显得未完成
- 「工坊」叙事已由 slogan 与产品结构承载，不必占品牌名位

### 5.1 改名时抓到的一处商标风险（重要留档）

落地页 hero 标题原为 **「极画AI电商图 上新快10倍 拍图成本直降90%」**——2026-10-17「营销文案完全照搬」的决策把**参考站商标「极画AI」也一起复制了**，与 README 既定原则「保留本项目自有品牌标识，不替换为参考站商标」正面冲突。

- 处置：品牌名替换为「货觉AI」，营销数字（上新快 10 倍 / 成本直降 90%）按原决策保留照搬
- 复盘：**「照搬文案」与「保留自有品牌」是两条会互相踩的规则**，批量复制商业文案时必须单独过一遍品牌名/商标词扫描（`grep -n "极画" frontend/src` 当前应无命中）
- 同类风险位：`public/landing/` 下的参考站图片素材自带对方水印/角标，属「完全照搬」决策覆盖范围，但与自有品牌同屏出现时仍建议在上线前 review
