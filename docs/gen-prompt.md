
# 生图
生图规范与提示词


## 商品主图
「立即生成」
实际链路：

上传商品图 + 商品信息 + 生成设置 + 商品描述 + 自定义配置
                    ↓
          一次生成请求
                    ↓
后端按 variants 展开为 N 个任务
                    ↓
每张图独立提示词、独立执行、独立计费和退款
                    ↓
按 batchId 聚合展示为同一次生成

## 各字段如何进入生成

上传商品图：作为真实参考图通过 inputAssetIds → request.images 传给模型；提示词同时写明参考图张数及商品一致性约束
商品名称、品牌： 进入提示词商品主体描述；卖点图中也作为允许出现的文案来源
平台： 转换为平台规格约束，例如“适配淘宝平台（主图常规 1:1、边长 ≥800px）” 
输出语言： 进入提示词，约束画面内文字语言
画面比例： 进入提示词，同时参与生成请求的尺寸意图
 画质： 进入提示词，例如“输出规格 1K/2K/4K”
 商品描述：  卖点图作为事实文案闭集；白底图、场景图、其他图作为“画面理解”上下文，但不允许把描述渲染成画面文字
 自定义配置：  决定生成类型和每种类型的张数
 模型选择：  用于选择实际模型线路，不直接作为提示词文本

其中商品描述的提示词处理已经补齐：

- 卖点图：描述可以作为画面文案来源。
- 白底图、场景图、其他图：描述用于理解商品属性、适用场景和构图，但明确禁止生成文字。
- 模型不得自行编造型号、参数、功效、认证、价格或促销承诺。

商品图本身不是简单转换成一句文字提示词，而是作为真正的参考图 media 传给模型。
