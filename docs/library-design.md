# 素材库页面设计规范（`/library`）

本规范约束素材库页面的字体层级、配色、按钮、标题、文案、间距、状态与响应式行为。目标是让“找素材、看素材、批量处理素材”成为同一条清晰路径，而不是堆叠筛选器。

| 项 | 现值 |
| --- | --- |
| 路由 | `/library`，别名 `/asset-library` |
| 页面组件 | `frontend/src/pages/library/page.tsx` |
| 样式 | `frontend/src/styles/global.css` 的 `.asset-library-*` 区块 |
| 组件来源 | `frontend/src/ui`；底层使用 shadcn / Radix 组合件 |
| 全站字体与令牌 | `docs/typography.md`、`frontend/src/styles/global.css` 的 `:root` |
| 数据接口 | `GET /assets`、`POST /assets/upload`、`DELETE /assets/:id` |

## 1. 设计原则

1. **图片优先**：网格卡片只保留封面；标题、尺寸、体积等非决策信息不进入卡片，避免图片被文字挤压。
2. **来源可辨**：上传原图必须有常驻标记；来源筛选、能力筛选和分组的结果必须能同时生效。
3. **一个主操作**：页面右上角只有“上传素材”使用主按钮；刷新、筛选、批量下载均降为次级或文字按钮。
4. **状态说人话**：加载、失败、游客、真实空库、筛选无结果必须分别解释原因和下一步，不能都显示“暂无数据”。
5. **批量操作渐进出现**：未选择时不占空间；选择后出现批量条，任务完成后可立即取消选择。
6. **控件不造轮子**：控件与容器优先使用 shadcn 组合件；页面不直连 `admin-ui`，统一从 `frontend/src/ui` 取件。

## 2. 页面结构

```text
素材库页面
├── 页面头部
│   ├── 标题「素材库」
│   ├── 一句用途说明
│   └── 来源筛选 / 能力筛选 / 刷新 / 上传素材
├── 分组面板（登录且有素材时）
│   ├── 分组标题与说明
│   ├── 分组方式：不分组 / 按项目 / 按能力 / 按日期
│   └── 分组结果：全部素材 + 各分组计数
├── 批量操作条（有选择时）
├── 内容区
│   ├── 加载骨架
│   ├── 加载失败
│   ├── 分类空态
│   └── 图片网格 + 加载更多
└── 图片预览查看器
```

## 3. 字体层级

全站最小字号为 12px。层级优先通过字号、字重和颜色区分，不靠过多颜色。

| 角色 | 字号 / 字重 / 行高 | 颜色 | 用法 |
| --- | --- | --- | --- |
| 页面标题 | 28 / 700 / 40；移动端 24 / 700 / 34 | `--text-strong` | 仅一级标题“素材库” |
| 页面副标题 | 13 / 400 / 20 | `--text-muted` | 一句话说明页面能力，不重复标题 |
| 区块标题 | 14 / 600 / 20 | `--text-strong` | 如“素材分组” |
| 区块说明 | 12 / 400 / 20 | `--text-muted` | 解释区块作用，不写实现细节 |
| 正文 | 14 / 400 / 22 | `--text-body` | 弹层、提示与表单正文 |
| 按钮文字 | 13 / 500 | 按按钮层级 | 页面级按钮、筛选触发器 |
| 胶囊标签 | 13 / 500 | 按选中态 | 分组方式与分组结果 |
| 辅助文字 / 计数 | 12 / 400 / 16–20 | `--text-muted` | 批量计数、剩余数量、来源标记 |
| 卡片操作 | 12 / 500 | `--on-brand` | 封面悬浮操作区 |

规则：

- 不使用小于 12px 的文字。
- 同一信息块最多使用两级字重：标题 600–700，正文/说明 400–500。
- 数字与中文混排时保持同一字号；计数不单独放大或加粗。
- 卡片内不添加标题、尺寸、体积、来源描述；来源信息只保留“上传原图”标记。

### 4.2 配色规则

- 页面只引用语义 token，不写裸 hex 或临时近似紫。
- 紫色只承担品牌与交互含义，不用于大面积背景。
- 选中态使用“品牌浅底 + 品牌描边 + 品牌文字”，不要只靠颜色深浅表达。
- 错误使用危险色；错误不能使用灰色空态样式伪装成“没有数据”。
- `--text-muted` 与 `--text-desc` 在白底和灰底上均按小字号对比度要求收敛为 `#667085`，层级由字号与字重承担。

## 5. 标题与内容文案

### 5.1 标题

- 页面标题固定为“素材库”，使用名词，不加装饰词。
- 副标题使用“管理对象 + 可完成动作”，当前文案为：
  - `统一管理上传原图与生成结果，支持筛选、分组、预览和批量下载`
- 区块标题控制在 2–8 个汉字，例如“素材分组”。
- 按钮内不重复标题，例如不在“素材分组”面板里再写“分组管理”。

### 5.2 动作文案

- 按钮使用“动词 + 对象”，最多 6 个汉字优先。
- 推荐：`上传素材`、`刷新列表`、`下载所选`、`取消选择`、`清除筛选`、`登录并上传`。
- 不使用：`确定`、`提交`、`操作`、`点击这里` 等失去上下文的泛词。
- 成功提示说明结果与数量，例如 `已上传 3 张素材`。
- 失败提示说明对象、原因和下一步，不把异常吞成“暂无数据”。

### 5.3 空态文案

空态必须同时回答“为什么空”和“接下来做什么”。

| 场景 | 标题 | 说明 | 操作 |
| --- | --- | --- | --- |
| 游客 | 登录后管理素材 | 上传原图或生成图片后，可在这里统一筛选、预览和下载。 | 登录并上传 |
| 有筛选但无结果 | 没有符合条件的素材 | 换个来源、能力或分组条件试试。 | 清除筛选 |
| 真实空库 | 还没有素材 | 上传原图后，可在这里统一筛选、预览和下载。 | 上传素材 |

规则：

- “筛选无结果”不是空库，必须提供“清除筛选”。
- 游客态不请求素材接口，不把 401 渲染成加载失败。
- 空态操作必须具备真实行为：登录、清除筛选或打开文件选择器。
- 错误态与空态互斥；接口失败必须显示错误说明与重试。

### 5.4 计数文案

- 批量：`已选 3 个素材`
- 分页：`加载更多（剩余 12 个）`
- 分组：分组名 + 独立数字，例如 `商品主图 8`，数字不加括号或单位。
- 计数为 0 时不显示无意义徽标。

## 6. 按钮设计

### 6.1 层级

| 层级 | shadcn 映射 | 页面样式 | 使用场景 |
| --- | --- | --- | --- |
| Primary | `Button type="primary"` → `default` | 品牌紫底、白字、42px 高、8px 圆角 | 上传素材、空态主动作 |
| Outline | `Button` / `type="default"` → `outline` | 白底、常规边框、次要文字 | 刷新、筛选触发器 |
| Ghost | `Button type="text"` → `ghost` | 透明底、按上下文着色 | 批量下载、取消选择、卡片操作 |
| Danger | `danger` / `Popconfirm okButtonProps.danger` | 危险色文字与确认态 | 删除素材及其产出记录 |
| Pill | `ToggleGroup` + `outline` | 32px 高、胶囊圆角 | 分组方式、分组结果 |

### 6.2 尺寸

| 控件 | 尺寸 |
| --- | --- |
| 页面级按钮 / Select 触发器 | 高 42px，水平内边距 11–15px，字号 13px |
| 分组胶囊 | 高 32px，水平内边距 12–14px，字号 13px |
| 卡片悬浮操作 | 高 31px，字号 12px，图标 12px |
| 卡片勾选 | 22 × 22px |
| 批量操作按钮 | 12px 字号，5–7px 内边距 |

### 6.3 状态

- **hover**：描边转为品牌色，浅紫底，文字转品牌交互色；不做位移或缩放。
- **focus-visible**：必须出现清晰品牌 focus ring，键盘可完整操作。
- **selected**：分组胶囊使用品牌浅底、品牌描边、品牌文字；卡片使用外描边，不改变尺寸。
- **disabled**：透明度约 48%，保留布局与可读标签，光标显示不可用。
- **loading**：按钮内显示 spinner 并禁用重复提交；文案保持稳定，避免按钮宽度跳动。
- **icon-only**：仅用于熟悉的删除图标等场景，且必须有 `aria-label` 与 `title`。

## 7. 表单与筛选控件

| 控件 | shadcn 组合 | 规范 |
| --- | --- | --- |
| 来源筛选 | `Select` | 选项为全部来源 / 原图 / 生成图 |
| 能力筛选 | `Select` | 选项为全部能力 + 真实能力清单 |
| 分组方式 | `ToggleGroup` | 单选，2–7 项；不使用循环 Button 手写选中态 |
| 分组结果 | `ToggleGroup` | “全部素材” + 当前聚合组，显示计数 |
| 多选素材 | `Checkbox` | 22 × 22，绝对定位封面左上角 |
| 删除确认 | `Popconfirm` | 说明影响范围，确认按钮使用危险态 |

筛选规则：

- 来源、能力、分组条件可叠加；结果为空时进入“筛选无结果”，不能显示真实空库文案。
- 切换分组方式时清空分组结果选择，回到“全部素材”。
- 分组不存在时自动回退，不保留无法命中的选中态。
- 筛选变化后清空已选素材，避免批量操作作用于旧结果。

## 8. 布局、间距与视觉

### 8.1 页面

| 项 | 桌面 | 移动端 |
| --- | --- | --- |
| 页面内边距 | `24px 24px 56px` | `18px 12px 36px` |
| 内容宽度 | 撑满可用工作区，不设固定宽度 | 同左 |
| 最小高度 | `calc(100vh - var(--workspace-topbar-height))` | 同左 |

- `.app-content` 与 `.asset-library-page` 只能有一层横向内边距。
- 桌面端页面逃逸工作区 padding 获取整幅宽度；改动任一 padding 都必须复核无横向溢出。

### 8.2 页面头部

- 使用 flex 两端对齐，底部对齐，gap 24px，下边距 22px。
- 标题区与操作区之间必须保留至少 24px 呼吸空间。
- ≤700px 时改为纵向排列，操作区换行显示。
- 游客隐藏筛选、刷新、上传，仅保留标题、副标题与登录空态。

### 8.3 分组面板

- 外观：白底、`--border` 描边、16px 圆角、`18px 20px` 内边距。
- 阴影：`0 8px 24px rgba(40, 37, 84, 0.03)`，仅用于把面板与图片网格分层。
- 标题与说明同基线排列，间距 10px；分组胶囊上边距 12px，间距 10px。
- 面板下边距 18px，与批量条/网格保持同一节奏。

### 8.4 图片网格

| 视口 | 列数 | 网格 gap |
| --- | --- | --- |
| >1200 | 5 | 16px |
| ≤1200 | 4 | 16px |
| ≤980 | 3 | 16px |
| ≤640 | 2 | 10px |
| ≤380 | 1 | 10px |

- 卡片为 fluid 宽度，禁止固定宽度。
- 封面固定 1:1，使用 `object-fit: cover`；视频使用 `object-fit: contain` 与深色底。
- 卡片是直角纯图卡：白底、1px 细边框、无圆角、无阴影。
- 不在卡片中显示标题、尺寸、体积或生成参数。
- 上传原图在封面右上角显示“上传原图”徽标；生成图不重复标注来源。
- 勾选位于左上角；查看、下载、再来一张、删除位于底部悬浮操作区。
- 悬浮操作仅在 hover、键盘 focus-within 或触屏环境显示。
- 选中态只增加品牌外描边，不放大、不上浮、不改变卡片尺寸。

### 8.5 上传原图徽标

- 组件：`StatusBadge variant="secondary"`。
- 文案：`上传原图`。
- 位置：封面右上角，距边 8px。
- 尺寸：高 24px、字号 12px、胶囊圆角。
- 配色：`--surface` 底、`--text-body` 文字；使用 shadcn 内置 `secondary` 变体，不覆写颜色。
- 不响应点击，不与复选框和底部操作争抢交互区域。

### 8.6 批量操作条

- 选择数量大于 0 时出现，位于分组面板和网格之间。
- 品牌浅底、8px 圆角、`10px 14px` 内边距，使用 `role="status"` 与 `aria-live="polite"`。
- 文案与操作顺序固定：选择数量 → 下载所选 → 取消选择。
- 删除批量素材必须二次确认，确认文案说明对作品记录的影响。

## 9. 状态与反馈

| 状态 | 表现 |
| --- | --- |
| 首次加载 | 使用 shadcn 风格骨架屏，占住约 10 张卡片与 5 列网格，内容到达时零位移 |
| 加载失败 | `StateError` + “素材加载失败” + 原因说明 + 重试；不得显示空态插画 |
| 游客 | 不请求 `/assets`，显示登录空态 |
| 真实空库 | 空态插画 + “还没有素材” + 上传素材 |
| 筛选无结果 | 同一空态容器，但标题、说明和操作按筛选场景替换 |
| 加载更多 | 全宽文字按钮，显示剩余数量；加载时禁止重复触发 |
| 上传成功 | 数量型成功反馈，刷新列表并保留当前筛选 |
| 上传失败 | 明确文件类型、体积、解码或权限问题；不能只提示“操作失败” |

空态与错误态是两种不同语义，禁止合并。空态插画仅用于“确实没有素材”和“筛选无结果”，接口错误使用错误组件。

## 10. 响应式

| 断点 | 页面调整 |
| --- | --- |
| ≤1200 | 网格 5 → 4 列 |
| ≤980 | 网格 4 → 3 列；页面 padding 改为 `24px 20px 44px` |
| ≤700 | 头部纵向排列；标题区与操作区占满宽度 |
| ≤640 | 网格 3 → 2 列，gap 10px；标题 24/34；页面 padding 改为 `18px 12px 36px` |
| ≤380 | 网格 2 → 1 列 |

移动端额外规则：

- 操作按钮允许换行，不压缩文字。
- 触屏没有 hover 时，卡片操作区常驻显示。
- 卡片必须保持方形，两列下不能被文字或 meta 撑高。
- 390px 视口不得出现横向滚动。

## 11. 无障碍与交互

- 页面标题使用唯一的 `h1`；区块标题使用语义标题。
- 所有筛选器、复选框、图标按钮必须有可读 `aria-label`。
- 键盘可依次聚焦筛选器、卡片、复选框和卡片操作；focus ring 不得被裁切。
- 图片有与素材类型对应的 `alt`；纯装饰空态插画使用空 `alt`。
- 批量状态使用 `aria-live="polite"`，删除确认可由键盘完成。
- 选中态不能只依赖颜色：同时使用描边、复选框或 `data-state` 表达。
- 点击区域不小于 31px；主要控件高度 42px。

## 12. shadcn 实现约束

| 页面区域 | 必须使用 |
| --- | --- |
| 分组面板 | `Surface` + `SurfaceHeader` + `SurfaceTitle` + `SurfaceDescription` + `SurfaceContent` |
| 筛选 | `Select` |
| 分组单选 | `ToggleGroup` |
| 操作按钮 | `Button` |
| 素材多选 | `Checkbox` |
| 来源标记 | `StatusBadge` |
| 空态 | `EmptyState` + `EmptyStateMedia` + `EmptyStateHeader` + `EmptyStateTitle` + `EmptyStateDescription` + `EmptyStateContent` |
| 删除确认 | `Popconfirm` |

实现规则：

- 页面统一从 `frontend/src/ui` 导入，不直接引用 `admin-ui/components/ui`。
- 条件类名使用 `cn()`；不使用模板字符串拼状态类。
- 不在页面中写组件色值；颜色通过语义 token 或 shadcn variant 表达。
- 覆盖层、弹层、下拉的层级由组件管理，不手写 `z-index`。
- 布局使用 flex/grid 与 `gap`，不使用 `space-x-*` / `space-y-*`。

## 13. Do / Don't

| Do | Don't |
| --- | --- |
| 用“上传素材”作为唯一主按钮 | 让刷新、筛选、下载都使用紫色实底 |
| 让上传原图带“上传原图”标记 | 让原图与生成图在网格中完全不可区分 |
| 用空态解释原因并提供真实下一步 | 所有无数据都写“暂无数据” |
| 用 1:1 纯图卡保持网格整齐 | 在卡片下方堆标题、尺寸、体积和来源 |
| 用品牌浅底 + 描边表达选中 | 用缩放、上浮和阴影制造跳动 |
| 用 shadcn 组合件与语义 token | 页面内手写按钮、下拉、颜色和 z-index |
| 筛选无结果时提供“清除筛选” | 把筛选无结果伪装成真实空库 |
