## 8. 购买、续费与到期

- 购买后自动顺延：当前没有有效会员时**立即生效**；当前会员仍有效时，新周期从当前到期时间**自动顺延**，不提前切换套餐、不提前发下一期积分、不提前改变用户分组。**无自动扣费、无隐形自动续费**，到期前需手动确认续费。
- 会员到期后：**已购买的永久积分补充包不受影响**；未用完的月度赠送积分不再保留；并发任务数回落免费基础额度。
- 虚拟算力资源，**购买后不支持退款**（购买前需确认套餐权益与积分配置）。

## 9. 商用授权与发票

- 生成的无水印成果著作权与商用权益**无条件转让给付费 VIP 用户**；产物是否具备独立知识产权仍需依现行法规与各电商平台（天猫、亚马逊等）规则判定。
- 企业开票：提供抬头与税号，1 个工作日内开具电子发票。

剩余未落地项按功能立项，不是改数据能解决的：

- **10 倍充值赠送**：需要在支付成功发放积分时按 `Product.credits × 倍率` 落批次，倍率与适用范围要进设置项。
- **VIP 签到双倍**：`checkinRule` 增加按会员档的倍率字段，签到结算时读会员快照。
- **子账号 / 团队资产**：需要成员关系表与资产共享权限，属账户域新模块。
- **积分滚存 / 年卡**：滚存要改 `membership.service.ts` 的月度发放与批次到期策略；年卡是 `durationDays: 365` 的档位加顺延逻辑。

## 11. 页面结构（当前实现）

`/packages` 由 `frontend/src/pages/PackagesPage.tsx` 渲染，价目、积分数与权益文案全部来自接口，页面不写死任何数值：

| 区块 | 现状 |
| --- | --- |
| 页头 | 返回按钮 + 积分商城标题 + 当前积分（登录态，点击进积分明细） |
| 会员套餐 | 免费档压成一行基线说明（`.pkg-free-strip`），不占卡片位；6 个付费档按 3×2 排列。角标取 `lib/constants.ts` 的 `PLAN_VISUALS`（与首页共用同一份），「最热门」档（专业版）额外描边 |
| 积分包 | 顶部按有效期筛选（全部 / 31 天 / 永久，数量实时取自接口，计数为 0 的分类不出现）；卡片显示积分数、有效期、折合单价（`priceCents / credits`，页面计算）与划线原价；「最划算」按每元积分数自动计算，只在付费商品间比较 |
| 购买说明 | 支付到账、按能力消耗价实时扣减、失败原额退还 |

首页「套餐与加油包」复用同一份 `PLAN_VISUALS`（6 档 3×2），加油包 tab 只陈列前 4 款，全量入口指向本页。
