## 1. 产品概述

### 1.1 背景

货觉AI 当前是本地演示环境：15 项图像能力中 7 项为本地真实算法、8 项为参数化占位；无账号注销、无计费、无管理后台。全站文案宣示"本地算力 · 不限次数"。

改造目标：把MVP 从演示环境变为**可对外收费运营的合规产品**。

### 1.2 产品定义

面向**个人电商从业者**（淘宝/拼多多/抖店个体户、微商）的商品图加工工具：上传已有商品图，按次付费，产出可上架的主图、详情图与修图结果。

### 1.3 能力范围

可售能力 7 项，全部为**确定性图像变换**：

| 能力 ID | 名称 | 分组 |
|---|---|---|
| `main_image` | 商品主图 | 电商生图 |
| `detail_image` | 商品详情图 | 电商生图 |
| `expand` | 智能扩图 | AI修图 |
| `matting` | 一键抠图 | AI修图 |
| `enhance` | 产品精修 | AI修图 |
| `recolor` | 商品换色 | AI修图 |
| `rotate` | 旋转角度 | AI修图 |

下架 8 项（占位能力）：`hot_remake`、`creative_image`、`multi_fusion`、`sku_image`、`local_redraw`、`remove_watermark`、`image_translate`、`free_create`。

**产品定位**：电商图批处理工具，非 AI 创作平台。

### 1.4 本期不做

多租户与团队版 · 真实支付通道（无商户号）· 占位能力补齐 · 自定义角色权限 · API 开放平台 · 邮件与短信以外的外部触达通道。

**权限模型**：

| 角色 | 权限范围 |
|---|---|
| 管理员 admin | 全部，含系统配置与角色管理 |

## 3. 数据需求

### 3.1 现有表（4）

`User` · `Project` · `Asset` · `GenerationTask`

### 3.2 新增表（17）

| 域 | 表 |
|---|---|
| 交易 | `Product` · `Order` · `OrderItem` |
| 资产 | `CreditLot` · `CreditLedger` |
| 合规 | `AigcStamp` · `ComplianceLog` |
| 权限 | `AdminRole` |
| 消息 | `Notification` · `Announcement` · `MessageTemplate` |
| 服务 | `Ticket` · `TicketMessage` |
| 配置 | `AdminAuditLog` · `SystemSetting` · `AccountToken`（密码重置） |

### 3.3 关键字段扩列

| 模型 | 新增字段 |
|---|---|
| `User` | `role`（user/admin/operator/finance）、`status`、`lastLoginAt` |
| `Asset` | `status`（visible/hidden） |
| `GenerationTask` | `creditCost` |
| `CapabilityDef` | `creditCost`（代码侧声明，作为消耗价兜底默认值） |

### 3.4 核心规则

**积分**：余额由 `CreditLot.remaining` 汇总推导，不设冗余余额字段。扣减按到期日升序（FEFO），`expireAt` 为空视为最晚。

**金额**：整数存储，单位为分。不使用浮点。

**订单**：`OrderItem` 全字段快照，商品改价不影响历史订单。下单按 `idempotencyKey` 幂等。

**生成扣费**：在创建任务前扣除，与建任务同事务。失败自动退还至新的永久批次。

**并发**：SQLite 单写者，不引入行锁。扣减用条件更新（`remaining >= cost`）配合 SERIALIZABLE 事务。

**权益声明**：`Product` 只承载「积分数量 + 有效期 + 发放方式」，不承载次数、通道、并发、折扣类权益。落地页现有订阅卡声明的 5 类权益中，4 类无模型承载。

## 4. 非功能需求

| 类别 | 要求 |
|---|---|
| 合规-标识 | 生成内容含显式标识（导出时必须）与隐式元数据（字段名含 `AIGC`） |
| 合规-个人信息 | 提供注销、更正、删除、导出通道；处理时限 ≤15 工作日 |
| 合规-交易留存 | 订单与交易信息保存 ≥3 年 |
| 安全-素材访问 | 素材不可凭裸 URL 公开访问 |
| 安全-越权 | 低权限账号访问高权限接口返回 403 |
| 安全-记账 | 余额唯一由批次汇总推导，禁止直接改余额 |
| 稳定性 | 外部通道失败时回落本地算法，用户始终可得结果 |
| 一致性 | 订单状态机不可跳跃；支付回调幂等 |
| 可观测 | 关键操作有日志；错误可追踪 |
