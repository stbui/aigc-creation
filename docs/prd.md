## 1. 产品定位

面向淘宝 / 拼多多 / 抖店个体户与小型电商团队的商品视觉工具：上传已有商品图或输入提示词，按次付费，产出可上架的主图、详情图、修图结果与短视频。

产品边界：

- 产出**只来自真实模型通道**。没有可用线路时任务失败并退款，不生成占位图、不回落本地算法、不交付伪结果。
- 能力清单由后端注册表驱动，前端不硬编码能力、价格或分组。
- 积分是唯一计费单位；价格、退款规则与活动由运营在后台配置，代码只提供默认值。
- 面向个人用户，不做团队协作、多租户与开放 API。

## 2. 用户与角色

| 角色 | 说明 | 关键权限 |
| --- | --- | --- |
| 访客 | 未登录 | 浏览首页、工作台、能力页、站点地图、法务正文；执行生成/上传时唤起登录弹窗 |
| 普通用户 | 已注册 | 创作、上传、素材库、作品、积分、订单、会员、工单、账户自助 |
| 后台角色 | 管理员 / 运营 / 财务 / 自定义 | 由 `AdminRole` 权限点控制；前端隐藏无权限入口，后端强制校验 |

普通账号与后台管理员是两套账号体系。普通账号永不被授予后台角色。

## 3. 能力范围

当前 16 项能力，全部 `real`，全部只由模型生成；12 项进工作台。

| 分组 | 能力 | 模态 | 默认积分 | 工作台 |
| --- | --- | --- | ---: | --- |
| 电商生图 | 商品主图 / 商品详情图 / 爆款复刻 / 创意生图 | image | 10 | 是 |
| | 多图融合 | image | 40 | 否 |
| | 商品SKU图 | image | 0 | 否 |
| AI修图 | 局部重绘 | image | 5 | 是 |
| | 智能扩图 / 图片翻译 / 产品精修 / 商品换色 / 旋转角度 | image | 5 | 是 |
| | 一键抠图 / 去除水印 | image | 0 | 是 |
| AI视频 | 自由创作 | image | 10 | 否 |
| | 图生视频 | video | 20 | 否 |

字段、提示词、默认积分价、参数与可见性只在 `backend/src/capabilities/definitions/<id>.ts` 声明。运行期价格一律经 `CreditPriceService.resolve()` 解析（后台覆盖价 / 限时免费优先于代码默认值）。

能力运行态：

| `runtime.effective` | 含义 | 用户可见行为 |
| --- | --- | --- |
| `remote` | 有可用模型线路 | 可提交，走真实模型 |
| `disabled` | 后台下线 | 入口隐藏；直接调用返回 `40005`，原因原样下发 |
| `unavailable` | 无可用线路，或存量 `route=local` | 入口保留；页面说明原因，已登录用户提交被拦截 |

**硬约束**：

- 扫码票据只存 SHA-256；扫码不等于授权，必须手机端确认；兑换一次性（`confirmed → consumed`）。
- 法务已发布版本不可原地覆盖；改文本须升版本号再发布。
- 注销说明必须写明订单留存 3 年，否则构成告知不准确。
- 第三方登录：`state` 绑定 provider 且 10 分钟过期（防 CSRF 与跨 provider 复用）；只有 provider 明确确权（`emailVerified`）的邮箱才自动绑定已有账号，其余一律新建本地账号；`accessToken` 不进 URL，回调只回传 60 秒短时票据，由前端换取正式会话；登录审计记 `reason=oauth:<provider>`。

**硬约束**：

- 余额唯一由批次汇总推导，禁止直接改余额。
- 金额以整数分存储；订单项使用快照，商品改价不影响历史订单。

## 5. 数据模型

43 个 Prisma 模型，按域分组：

| 域 | 模型 |
| --- | --- |
| 用户与权限 | `User` / `AdminRole` / `AdminAuditLog` / `SystemSetting` |
| 创作 | `Project` / `Asset` / `GenerationTask` |
| 交易 | `Product` / `Order` / `OrderItem` / `Payment` / `Refund` |
| 权益 | `CreditLot` / `CreditLedger` / `MembershipPlan` / `Membership` / `MembershipUsage` |
| 增长 | `Coupon` / `Campaign` / `InviteRelation` / `InviteRewardRule` / `CheckinRecord` / `CheckinRule` |
| 财务 | `Invoice` / `ReconciliationBatch` / `ReconciliationItem` |
| 身份安全 | `AccountToken`（一次性令牌：重置密码等）/ `LoginLog` / `LoginSession`（扫码登录票据，**只存 SHA-256 哈希**，`confirmed → consumed` 一次性兑换）/ `OAuthIdentity`（第三方绑定：`provider` + `subject` 联合唯一，`lastLoginAt` 记录最近登录） |
| 内容与合规 | `LegalDocument`（按 slug + version 版本化）/ `ConsentRecord`（同意留痕）/ `Notification` / `MessageTemplate` / `AigcLabelConfig`（单行 `id='default'`：`specJson` 样式 + `pngBase64` 浏览器渲染位图 + `specKey` 过期判定） |
| 服务 | `Ticket`（`ticketNo @unique`，状态机见 `tickets.service.ts` 的 `TRANSITIONS`）/ `TicketReply` |
| 模型通道 | `ModelChannel` / `ModelChannelConfig` / `ModelCallLog` / `CapabilityControl`（能力上下线，**无行 = 启用**） |
| 运维 | `BackupRecord` / `CleanupLog` |

SQLite 不支持 Prisma enum，状态类字段一律 String + DTO 白名单。`Asset.kind` = `original` | `generated`；`Asset.outputOfTask` 是 1:1 反向关系。计费相关字段以快照为准（`GenerationTask.creditCost`、`OrderItem.priceCentsSnapshot` / `creditsSnapshot`），不按当前价重算。

Jimp 仅用于上传校验、尺寸探测和 AIGC 角标合成，不参与生成图内容；生成图文字由模型决定。

## 6. 非功能需求

| 类别 | 要求 |
| --- | --- |
| 合规-标识 | 生成内容写隐式元数据；显式角标默认开启且后台可配 |
| 合规-个人信息 | 提供注销、更正、删除、导出通道；处理时限 ≤15 工作日 |
| 合规-交易留存 | 订单与交易信息保存 ≥3 年 |
| 安全-素材访问 | 素材不可凭裸 URL 公开访问（签名开启时） |
| 安全-越权 | 低权限账号访问高权限接口返回 403；越权访问他人资源返回 404 |
| 安全-记账 | 余额唯一由批次汇总推导，禁止直接改余额 |
| 稳定性 | 外部通道失败时显式失败并退款，不交付伪结果 |
| 一致性 | 订单状态机不可跳跃；支付回调幂等 |
| 可观测 | 关键操作有日志；错误可追踪；健康检查分项 |
| 性能 | 列表分页；后台批量动作串行并逐条返回结果 |

## 7. 明确不做

- 多租户与团队协作
- 开放 API 平台与第三方生态
- 原生移动 App（手机上传走扫码 Web 流程）
- 团队版组织/佣金体系
- 内容安全送审与标识自检巡检（当前为规划）
